# Задачи

- **Источник:** `docs/spec/requirements.md` (REQ-001…REQ-027), `docs/spec/consistency-model.md`, `docs/spec/protocol.md`
- **Правила:** задача ≤ 1 PR; размер S (≤ 2 ч) или M (≤ 1 день); `done` — только со ссылкой на коммит/PR; ID задач не меняются. Проверяется `npm run check:trace`: каждое REQ входит хотя бы в одну задачу, у REQ из задач со статусом `done` есть тесты с этим ID.
- **Порядок:** ядро CRDT → протокол и сервер → клиент → сквозные сценарии.
